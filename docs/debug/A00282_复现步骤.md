## 运行 Accuracy Benchmark（复现乱码的关键）

### 前置条件

在 **Node 0（Leader）** 上执行（只需装一次）：

```bash
cd /vllm-workspace/vllm-ascend
pip install -r requirements-dev.txt

# 安装 ais_bench benchmark 包
cd benchmark
pip install -e . -r requirements/api.txt -r requirements/extra.txt
```

### 手动跑 Accuracy 测试（多并发复现乱码）

```bash
# 1. 创建工作目录
export BENCHMARK_HOME="/tmp/aisbench_work"
mkdir -p $BENCHMARK_HOME/ais_bench/benchmark/configs/models/vllm_api
mkdir -p $BENCHMARK_HOME/ais_bench/benchmark/configs/datasets/gsm8k
mkdir -p $BENCHMARK_HOME/ais_bench/datasets

# 2. 创建自定义请求配置文件（accuracy）
cat > $BENCHMARK_HOME/ais_bench/benchmark/configs/models/vllm_api/vllm_api_general_chat_custom.py << 'EOF'
from ais_bench.benchmark.models import VLLMCustomAPIChat
from ais_bench.benchmark.utils.postprocess.model_postprocessors import extract_non_reasoning_content

models = [
    dict(
        attr="service",
        type=VLLMCustomAPIChat,
        abbr="vllm-api-general-chat",
        path="",
        model="/mnt/weight/Qwen3-235B-A22B",
        stream=False,
        request_rate=0,
        use_timestamp=False,
        retry=2,
        api_key="",
        host_ip="80.48.37.120",
        host_port=8080,
        url="",
        max_out_len=7680,
        batch_size=256,
        trust_remote_code=True,
        generation_kwargs=dict(
            temperature=0.6,
            ignore_eos=False,
        ),
        pred_postprocessor=dict(type=extract_non_reasoning_content),
    )
]
EOF

# 3. 拷贝数据集配置文件（从已安装的 ais_bench 复制）
cp /usr/local/python3.12.13/lib/python3.12/site-packages/ais_bench/benchmark/configs/datasets/gsm8k/gsm8k_gen_0_shot_cot_chat_prompt.py \
   $BENCHMARK_HOME/ais_bench/benchmark/configs/datasets/gsm8k/

# 4. 拷贝 summarizer 配置
mkdir -p $BENCHMARK_HOME/ais_bench/benchmark/configs/summarizers
cp /usr/local/python3.12.13/lib/python3.12/site-packages/ais_bench/benchmark/configs/summarizers/example.py \
   $BENCHMARK_HOME/ais_bench/benchmark/configs/summarizers/

# 5. 跑 accuracy benchmark
BENCHMARK_HOME="/tmp/aisbench_work" \
ais_bench --models vllm_api_general_chat_custom \
          --datasets gsm8k_gen_0_shot_cot_chat_prompt \
          --debug 2>&1 | tee /tmp/benchmark_acc.log
```

> 注意：第 3 步的 Python 版本路径（`python3.12.13`）以实际容器为准，可用 `ls /usr/local/` 确认。

### 预期结果

- **数据集**: gsm8k-lite
- **batch_size**: 256（高并发，触发乱码）
- **baseline**: 96，**threshold**: 5（acc ≥ 91% 算通过）
- **正常（成功版）**: ~96.875%
- **异常（失败版）**: 0.0% / 3.125%（全乱码）

accuracy 由 ais_bench 写入 CSV，`AisbenchRunner` 从 CSV 末列读取。

## 注意事项

- 两节点之间需互通 **8080**（API）和 **13389**（DP RPC）端口
- 权重路径：`/mnt/weight/Qwen3-235B-A22B`
- `vllm` / `vllm-ascend` 需先在两个节点上装好（版本必须一致）
- `--async-scheduling` 对齐 A2 nightly yaml（回归版一直使用）
- `--safetensors-load-strategy prefetch` 非 5/9 原始参数，仅加速权重加载；老版本整包若报 `unrecognized arguments` 可去掉
- **每次改完代码/参数，两个节点都要重新 `pip install -e .` 并重启 serve**
