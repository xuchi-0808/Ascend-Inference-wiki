# 操作指南 Guides

读者带着一个想完成的事来，离开时把事做成。收录操作指南与教程，按场景分组：

- **环境搭建**（environment）—— 编译安装、依赖配置
- **部署拉起**（deployment）—— 单机/多机 serve、容器编排
- **测试压测**（benchmarking）—— AISBench、accuracy/perf
- **性能调优**（tuning）—— 调参、profile、瓶颈定位
- **故障排查**（troubleshooting）—— OOM、hang、精度异常
