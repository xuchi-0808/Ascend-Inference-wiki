## Node 0（Leader / Master）— 在 80.48.37.120 上执行

> 使用 2 节点 × 8 张 NPU，TP=8, DP=2

```bash
# === 环境变量 ===
export VLLM_USE_MODELSCOPE=true
export OMP_PROC_BIND=false
export OMP_NUM_THREADS=1
export HCCL_BUFFSIZE=1024
export SERVER_PORT=8080
export NUMEXPR_MAX_THREADS=128
export TASK_QUEUE_ENABLE=1
export PYTORCH_NPU_ALLOC_CONF=expandable_segments:True
export HF_HUB_OFFLINE=1
export VLLM_ENGINE_READY_TIMEOUT_S=1800
export VLLM_LOGGING_LEVEL=INFO
export GLOG_minloglevel=1
export VLLM_WORKER_MULTIPROC_METHOD=spawn

# === 网络相关 ===
export MASTER_IP=80.48.37.120
export LOCAL_IP=80.48.37.120
export HCCL_IF_IP=80.48.37.120
export NIC_NAME=enp189s0f0
export HCCL_SOCKET_IFNAME=enp189s0f0
export GLOO_SOCKET_IFNAME=enp189s0f0
export TP_SOCKET_IFNAME=enp189s0f0

# === 启动 ===
vllm serve "Qwen/Qwen3-235B-A22B" \
    --host 0.0.0.0 \
    --port $SERVER_PORT \
    --data-parallel-size 2 \
    --data-parallel-size-local 1 \
    --data-parallel-address $LOCAL_IP \
    --data-parallel-rpc-port 13389 \
    --tensor-parallel-size 8 \
    --seed 1024 \
    --enable-expert-parallel \
    --max-num-seqs 128 \
    --max-model-len 40960 \
    --max-num-batched-tokens 2048 \
    --trust-remote-code \
    --gpu-memory-utilization 0.9
```

## 启动顺序

1. **先起 Node 1（Worker）** — headless 节点先启动，等待 Leader
2. **再起 Node 0（Leader）** — Leader 启动后自动与 Worker 建立 DP 连接

## 注意事项

- 两个节点之间需要互通 **8080**（API）和 **13389**（DP RPC）端口
- 权重路径：**`/mnt/weight/Qwen3-235B-A22B`**，如使用 `Qwen/Qwen3-235B-A22B` 做 model name，需提前建好软链接：

  ```bash
  mkdir -p /root/.cache/modelscope/hub/models/Qwen
  ln -s /mnt/weight/Qwen3-235B-A22B /root/.cache/modelscope/hub/models/Qwen/Qwen3-235B-A22B
  ```

  或者直接用路径拉起：`vllm serve /mnt/weight/Qwen3-235B-A22B ...`
- `vllm` / `vllm-ascend` 需先在两个节点上装好
