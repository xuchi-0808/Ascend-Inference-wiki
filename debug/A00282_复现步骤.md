#### 初始化顺序修复（必须做！）

vllm 726efe177 的 `qwen3_moe.py` 改用 `SharedFusedMoE`，触发 vllm-ascend 68ff5263 的初始化顺序 bug：

```text
AttributeError: 'AscendSharedFusedMoE' object has no attribute '_routed_input_transform'
```

**原因**：`AscendSharedFusedMoE.__init__` 先调 `AscendFusedMoE.__init__`（内部访问 `self._routed_input_transform`），后设这个属性。

**修复**：把 `self._routed_input_transform = routed_input_transform` 移到 `AscendFusedMoE.__init__` 之前。

文件：`vllm_ascend/ops/fused_moe/fused_moe.py`，`AscendSharedFusedMoE.__init__` 方法里（约 line 573 附近）。

修改前：

```python
        AscendFusedMoE.__init__(self, **kwargs)
        if ascend_config.mix_placement:
            rocm_aiter_ops.is_fusion_moe_shared_experts_enabled = mock_true
            rocm_aiter_ops.is_fused_moe_enabled = mock_true

        self._routed_input_transform = routed_input_transform
```

修改后：

```python
        self._routed_input_transform = routed_input_transform
        AscendFusedMoE.__init__(self, **kwargs)
        if ascend_config.mix_placement:
            rocm_aiter_ops.is_fusion_moe_shared_experts_enabled = mock_true
            rocm_aiter_ops.is_fused_moe_enabled = mock_true
```

> 这个修复只调整初始化顺序，不改 MC2/cudagraph 逻辑，不影响实验判据。

## 注意事项

- 两个节点之间需互通 **8080**（API）和 **13389**（DP RPC）端口
- **CWD 陷阱**：起 serve 前不要 `cd /vllm-workspace`，否则 `vllm` 被 Python 当相对目录解析 → `ImportError`。改用 `cd /root`
- **NPU 清理**：每次拉起前必须清设备（避免 507033）
- **改代码后确认生效**：`python3 -c "import vllm_ascend.ascend_forward_context as m; print(m.__file__)"` 应指向你改的文件
- `--safetensors-load-strategy prefetch` 非 5/9 原始参数，仅加速权重加载；老版本若报 `unrecognized arguments` 可去掉
