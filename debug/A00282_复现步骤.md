## 运行 Accuracy Benchmark

### 前置条件：安装 benchmark 工具

在 **Node 0（Leader）** 上执行（只需装一次）：

```bash
# 1. 安装 vllm-ascend（如果还没装）
cd /vllm-workspace/vllm-ascend
pip install -r requirements-dev.txt
pip install -e .

# 2. 安装 ais_bench benchmark 包
cd benchmark
pip install -e . -r requirements/api.txt -r requirements/extra.txt

# 3. 设置 benchmark 路径
export BENCHMARK_HOME=/vllm-workspace/vllm-ascend/benchmark
```

### 前提：vllm serve 已运行

Node 0（Leader）和 Node 1（Worker）都已正常拉起，API 可用。

### 方式一：pytest（推荐，与 CI 一致）

只在 **Node 0（Leader）** 上执行，会自动下载数据集、配置参数并跑 benchmark：

```bash
cd /vllm-workspace/vllm-ascend
export BENCHMARK_HOME=/vllm-workspace/vllm-ascend/benchmark
export CONFIG_YAML_PATH=Qwen3-235B-A22B-A2.yaml
export CONFIG_BASE_PATH=tests/e2e/nightly/multi_node/internal_dp/config/

pytest -sv --show-capture=no \
  tests/e2e/nightly/multi_node/internal_dp/scripts/test_multi_node.py::test_multi_node
```

### 方式二：Python 脚本（server 已就绪时单独跑 accuracy）

```python
import os
os.environ["BENCHMARK_HOME"] = "/vllm-workspace/vllm-ascend/benchmark"

from tools.aisbench import AisbenchRunner

case = {
    "case_type": "accuracy",
    "dataset_path": "vllm-ascend/gsm8k-lite",
    "request_conf": "vllm_api_general_chat",
    "dataset_conf": "gsm8k/gsm8k_gen_0_shot_cot_chat_prompt",
    "max_out_len": 7680,
    "batch_size": 256,
    "baseline": 96,
    "threshold": 5,
    "case_name": "acc",
}

with AisbenchRunner(
    model="/mnt/weight/Qwen3-235B-A22B",
    port=8080,
    host_ip="localhost",
    aisbench_config=case,
) as runner:
    print(f"Accuracy: {runner.result}")
```

### 预期结果

- **数据集**: gsm8k-lite（lite 版）
- **baseline**: 96, **threshold**: 5（期望 ≥ 91%）
- **正常**: ~96.875%（2026-05-09 成功值）
- **异常**: 0.0% / 3.125%（当前失败值）

accuracy 值由 ais_bench 工具计算并写入 CSV，`AisbenchRunner` 从 CSV 末列读取。
