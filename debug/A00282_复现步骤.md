## 配置对应关系

| 节点 | 角色 | 备注 |
|---|---|---|
| Node 0 | Leader（API Server） | 对外提供 API 服务 |
| Node 1 | Worker（headless） | 只参与计算，不暴露 API |

> 本测试使用 **2 节点 × 8 张 NPU**，TP=8, DP=2（每节点 1 个 DP rank）

---

## Node 0（Leader / Master）

### 环境变量

```bash
# === 从 run.sh / yaml 集成 ===
export VLLM_USE_MODELSCOPE=true
export OMP_PROC_BIND=false
export OMP_NUM_THREADS=1
export HCCL_BUFFSIZE=1024
export SERVER_PORT=8080
export NUMEXPR_MAX_THREADS=128
export TASK_QUEUE_ENABLE=1
export PYTORCH_NPU_ALLOC_CONF=expandable_segments:True
export HF_HUB_OFFLINE=1
export VLLM_ENGINE_READY_TIMEOUT_S=1800
export VLLM_LOGGING_LEVEL=INFO
export GLOG_minloglevel=1
export VLLM_WORKER_MULTIPROC_METHOD=spawn

# === 网络相关（请替换为实际 IP 和网卡名） ===
export MASTER_IP=<Node0_IP>       # 例如 10.0.3.79
export LOCAL_IP=<Node0_IP>        # 与 MASTER_IP 相同（Node 0 自己就是 master）
export HCCL_IF_IP=<Node0_IP>
export NIC_NAME=eth0              # 根据实际网卡名调整
export HCCL_SOCKET_IFNAME=eth0
export GLOO_SOCKET_IFNAME=eth0
export TP_SOCKET_IFNAME=eth0
```

### 启动命令

```bash
vllm serve "Qwen/Qwen3-235B-A22B" \
    --host 0.0.0.0 \
    --port $SERVER_PORT \
    --data-parallel-size 2 \
    --data-parallel-size-local 1 \
    --data-parallel-address $LOCAL_IP \
    --data-parallel-rpc-port 13389 \
    --tensor-parallel-size 8 \
    --seed 1024 \
    --enable-expert-parallel \
    --max-num-seqs 128 \
    --max-model-len 40960 \
    --max-num-batched-tokens 2048 \
    --trust-remote-code \
    --gpu-memory-utilization 0.9
```

### 环境变量

```bash
# === 从 run.sh / yaml 集成（与 Node 0 公共部分相同） ===
export VLLM_USE_MODELSCOPE=true
export OMP_PROC_BIND=false

export HCCL_BUFFSIZE=1024
export SERVER_PORT=8080

export TASK_QUEUE_ENABLE=1
export PYTORCH_NPU_ALLOC_CONF=expandable_segments:True
export HF_HUB_OFFLINE=1
export VLLM_ENGINE_READY_TIMEOUT_S=1800
export VLLM_LOGGING_LEVEL=INFO

export VLLM_WORKER_MULTIPROC_METHOD=spawn

# === 网络相关（请替换为实际 IP 和网卡名） ===
export MASTER_IP=<Node0_IP>       # 指向 Leader 的 IP
export LOCAL_IP=<Node1_IP>        # 本机 IP
export HCCL_IF_IP=<Node1_IP>

export HCCL_SOCKET_IFNAME=eth0
```

### 启动命令

```bash
vllm serve "Qwen/Qwen3-235B-A22B" \
    --headless \
    --data-parallel-size 2 \
    --data-parallel-size-local 1 \
    --data-parallel-start-rank 1 \
    --data-parallel-address $MASTER_IP \
    --data-parallel-rpc-port 13389 \
    --tensor-parallel-size 8 \
    --seed 1024 \
    --enable-expert-parallel \
    --max-num-seqs 128 \
    --max-model-len 40960 \
    --max-num-batched-tokens 2048 \
    --trust-remote-code \
    --gpu-memory-utilization 0.9
```

## 启动顺序

1. **先起 Node 1（Worker）** — headless 节点先启动，等待 Leader
2. **再起 Node 0（Leader）** — Leader 启动后会自动与 Worker 建立 DP 连接
